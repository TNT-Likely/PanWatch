# 台股／美股市場調整

## 資料口徑

| 功能 | 台股 | 美股 |
| --- | --- | --- |
| 標的搜尋 | 證交所上市與櫃買中心上櫃盤後清單 | 原有美股清單與搜尋 |
| 報價、熱門榜單 | 官方最新盤後資料，價格 TWD、量為股 | 原有報價來源 |
| 歷史日 K 線與技術指標 | Yahoo `.TW` / `.TWO`，未調整 OHLC | 原有 Yahoo／Stooq 路由 |
| 指數 | 證交所加權指數盤後值 | 納斯達克、道瓊斯 |
| 交易日 | 證交所年度開休市表 | 既有週末判斷 |
| 持倉彙總 | 新台幣 | 以 USD/TWD 換算成新台幣 |

官方盤後資料可能是上一個交易日，畫面會顯示盤後口徑。台股自動盤中監測與過期價格提醒已停用，避免拿昨收觸發盤中操作訊號。台股模擬盤是簡化估算，沒有實際手續費與交易稅；美股模擬下單暫停，直到換匯與費用模型具備逐筆記錄。

## 現有資料

CN/HK 歷史資料保留在資料庫，不會自動刪除。新建自選只接受 TW/US；舊持倉與舊模擬交易紀錄不會自動換幣。既有帳戶現金標記為 CNY，彙總時依 CNY/TWD 匯率換算；新帳戶現金預設 TWD，編輯舊帳戶現金後改以 TWD 保存。舊模擬盤本金仍需手動核對與重設。
