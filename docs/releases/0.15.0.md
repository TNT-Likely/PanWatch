# PanWatch 0.15.0

## Highlights

- Start stock discovery directly from the AI assistant, with a more usable mobile experience.
- Inspect assistant execution time and token usage from the trace instead of treating an AI run as a black box.
- Follow the complete TradingAgents deep-analysis workflow through a new public flowchart.

## Changes

- Added the assistant stock-discovery entry and refined its mobile layout.
- Added duration and token details to assistant execution traces.
- Consolidated assistant execution on the current runtime and removed the retired legacy chat path.
- Moved retrospective recommendation evaluation to an off-hours schedule to reduce contention with market-time workloads.
- Retired the legacy news-digest agent while preserving existing history.
- Added the TradingAgents deep-analysis flowchart and related documentation.

## Upgrade notes

- Back up the `/app/data` volume before upgrading.
- Pull `sunxiao0721/panwatch:0.15.0` for a pinned deployment, or `sunxiao0721/panwatch:latest` to follow the newest stable release.
- Recreate the container with the same data volume. Database migrations run automatically at startup.

## Compatibility and known issues

- No manual configuration migration is required.
- Existing history from the retired news-digest agent remains readable, but the agent can no longer be scheduled or run.
- AI features still require a configured OpenAI-compatible provider and may incur provider charges.
