# PanWatch Documentation / 项目文档

[English](#english) · [简体中文](#简体中文)

PanWatch is a self-hosted AI stock monitoring and portfolio research workspace for
China A-shares, Hong Kong, and U.S. markets. This page is the stable entry point
for installation, upgrades, architecture, releases, security, and contributions.

盯盘侠 PanWatch 是覆盖 A 股、港股和美股的自托管 AI 盯盘与持仓研究工作台。本页作为
安装、升级、架构、版本、安全和参与贡献的稳定文档入口。
