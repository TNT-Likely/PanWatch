# 报告、PR 与人工验收交付

完整执行证据置于私有 run 或 .docs/，不提交。源码、测试、技能和复用工具可提交。

## 本地报告包

在 run/report/ 内制作实际文件：

- index.html：离线可打开，先展示需求、操作、截图、业务数据对照、逐项状态和限制。
- OPEN.md：解压打开说明、版本、自动验收时间和当前人工验收环境状态。
- evidence/：脱敏截图和 JSON；引用使用包内相对路径。
- manifest.json：文件大小/hash、业务 SHA/内容 hash、构建 hash、run ID、技能版本/hash。
- SHA256SUMS：文件校验表。先完成其他内容，再生成 manifest 的文件清单（不包含 manifest 自身和 SHA256SUMS）；最后校验表包含 manifest，排除校验表自身。ZIP 自身 hash 留在包外。

技术信息置于折叠附录。HTML 图片/样式/脚本均来自包内，不依赖 CDN、运行服务、file:// 或本机绝对路径。检查桌面和窄屏、长路径/JSON 换行及证据引用。

排除凭证、token、AI/通知密钥、真实持仓、DB、备份、原始日志、浏览器 storage state、环境文件和构建二进制。只公开合成数据和必要身份；从私有 manifest 选取脱敏字段，不直接复制本机路径与敏感配置。

ZIP 仅包含 report/ 公开内容。打包前检查隐私、清单与引用，打包后解压至新目录核对路径、hash 和离线打开。报告是自动验收快照；另记交付时环境状态，不用旧 fixture 覆盖用户新数据。

## PR

完整功能交付默认自动提交本次源码、测试和可复用工具，推送本次用途分支，创建或更新 PR 并上传脱敏测试报告；用户已明确约定，无需重复询问。用户明确限制为仅本地、不推送、不建 PR 或不上传时遵循限制。先查询当前分支是否已有目标 PR，已有则更新，避免重复创建。检查提交范围及 git diff --check，不提交 .docs/、AGENTS.md 或他人改动，不直接推送 main。

PR 关联本次实际验证的源码 SHA／内容 hash 和构建 hash。提交前后核对内容一致，提交产生的新 SHA 与原验收快照的关系写入交付回执；不能只修改报告里的 SHA 来声称新版已验收。失败或未完成项必须显式说明，必要时用 draft PR 保留可审查结果。

英文 Conventional Commits 标题，正文使用当前 .github/PULL_REQUEST_TEMPLATE.md：

| 部分 | 应填写的实际内容 |
|---|---|
| Background | 用户问题、触发方式及影响 |
| Changes | 模块对应的最终行为 |
| Validation | 已执行命令/结果、实服 UI/API/runtime 覆盖、版本、报告 ZIP 下载链接及 SHA256 |
| Boundaries and risks | 失败、未执行、模拟边界、兼容性与依赖 |
| Follow-up | 确实延期的事项；没有则 None |

失败后独立复核成功仍保留原执行失败说明；跨仓依赖仅列实际存在的版本。CI pending 与通过分开。合并方式默认 squash，合并/部署/发版依当前授权执行。

PR 创建后，若工具提供 attach_artifact，将新 PR 附到当前对话；更新/继续目标 PR 时也附上。参考 PR 不作为本任务产物。

## 独立附件

测试报告是 PR 的标准附件，采用包含离线 HTML、脱敏截图、逐项结果、版本身份和校验表的独立 ZIP，不以正文摘要替代完整报告，也不将报告加入源码提交。

执行 [GitHub PR 附件交付](github-pr-attachments.md)：固定包，核对身份、隐私和 hash，通过网页文件选择器自动上传，将真实下载链接、打开说明及 SHA256 写入最新 PR 正文并回下载校验。CLI/API 没有 ZIP 上传接口不代表只能由用户手动上传。

仅本地交付或实际上传受阻时给 HTML/ZIP 绝对文件链接、hash 和打开说明。受阻不影响其他已获授权的 PR 步骤；正文注明 `Report attachment pending` 及具体原因。已上传但下载校验未完成时注明该阶段，不能写成全部交付完成。没有外部链接时不制造下载入口，不为报告新建 Release、仓库或托管。

## 人工交接

给源码/产物身份、当前 loopback URL、对象及建议操作、报告/ZIP、已通过层级和未执行部分。凭证通过私有文件交接。

保留同一服务和登录页面。再次打开复用同一版本与环境，不重新导出、重装、清空或 fixture。

用户明确验收完成或要求关闭后，核对 PID、启动身份、命令和监听，再停止本次资源；保留数据/报告。PR、打包或结束聊天不触发关闭。
